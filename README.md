<h1 align="center">📱 AndroidWebViewApp</h1>

<p align="center">
  <b>A Kotlin-based Android app using Jetpack Compose to render secure, responsive web content inside a WebView</b><br>
  <sub>Developed by <a href="https://github.com/shashankksoni">Shashank Kumar Soni</a></sub>
</p>

---

## 🚀 Features

- ⚡ Built using Jetpack Compose & Material 3
- 🌐 WebView with full JavaScript and DOM Storage support
- 📏 Auto-injection of `<meta viewport>` for responsive rendering
- 🔁 Retry mechanism for handling WebView load errors
- 🔙 Back press support within WebView history
